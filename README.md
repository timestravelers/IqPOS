# 🏪 IqPOS Professional Edition

## 🚀 Aplikasi Kasir Offline untuk Toko & Bisnis Retail

**Kasir lebih cepat. Stok lebih tertib. Bisnis lebih terkontrol.**

IqPOS Professional Edition adalah aplikasi kasir **offline** yang dirancang untuk membantu pemilik toko mengelola penjualan, stok, pembelian, supplier, pelanggan, kasir, shift, dan laporan bisnis dalam satu aplikasi.

Tidak perlu koneksi internet untuk melakukan transaksi.

**Download → Install → Coba Trial → Rasakan Sendiri.**

## 💡 Masih Mengelola Toko Secara Manual?

Apakah Anda masih mengalami masalah seperti:

* ❌ Sulit mengetahui penjualan hari ini
* ❌ Stok barang tidak sesuai dengan kondisi sebenarnya
* ❌ Sulit mengetahui barang yang mulai habis
* ❌ Tidak tahu berapa omset dan laba
* ❌ Kesulitan melacak transaksi kasir
* ❌ Nota transaksi sulit dicari kembali
* ❌ Data pembelian supplier tidak tertata
* ❌ Takut kehilangan data transaksi

IqPOS dibuat untuk membantu menyelesaikan masalah tersebut.
